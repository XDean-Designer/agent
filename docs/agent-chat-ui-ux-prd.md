## 1. 概述

### 1.1 目标

用统一的视觉语言与交互质感呈现 **AI Agent 对话窗口**（半屏 Sheet / 全屏），使价目结果卡、开单确认卡、追问白卡、输入条等组件在移动端具备 **轻拟物、品牌粉紫氛围、iOS 级动效质感**，并可被前端完整还原。

### 1.2 范围边界

**本文包含**

- Agent 窗体双态（半屏 / 全屏）的布局、背景、圆角、层级
- Header、会话区、Composer 的视觉与交互态
- 聊天气泡、思考态、功能结果卡（价目 / 开单）、追问白卡、Toast、滚动提示
- Design Tokens、按钮 / Chip 体系、动效规格、资源清单、验收清单

**本文不包含**

- 业务规则、接口、数据模型、审批/开单算法
- 桌面预览壳（左侧原型导航、深色舞台背景）的产品化要求  
  （半屏下「首页背景 + 遮罩」作为 Agent 半屏语境的一部分，见 §3）
- 文案内容策略（仅标注字号/颜色；示例文案可替换）

### 1.3 还原原则

1. **数值优先**：以本文 Token 与组件表为准；原型与本文冲突时以本文为准，并回改原型。
2. **态完整**：每个可交互控件至少覆盖默认 / 按压 / 选中（若有）/ 弱化（若有）。
3. **动效可测**：曲线、时长、位移、缩放均给出数值；支持 `prefers-reduced-motion`。
4. **功能卡 ≠ 气泡**：价目 / 开单结果使用「轻拟物白卡」；Agent 短文本使用「会话白卡（不对称圆角）」；用户消息使用粉红气泡。

## 2. 设计原则

| 原则 | 说明 |
|------|------|
| 品牌氛围 | 粉—紫—暖杏光斑与渐变，避免冷灰科技风、避免紫色扁平仪表盘感 |
| 轻拟物层次 | 白卡 + 极淡描边 + 柔和投影 + 顶栏浅色渐变，区分「系统结果」与「聊天」 |
| 信息层级 | 标题 15–18 / 正文随字号档 / 辅助 11.5–12；金额用 tabular-nums + 加粗 |
| iOS 质感 | Spring 曲线、短按压缩、卡片升起入场、HUD 毛玻璃 Toast；禁止夸张弹跳与长循环装饰动画 |
| 触控友好 | 主按钮高度 ≥ 34pt，底栏操作区 min-height 36；Chip 可多行折行，间距 8 |

## 3. 画布与双态窗体

### 3.1 画布

| Token / 属性 | 值 |
|--------------|-----|
| 逻辑宽 `--lw` | 390px |
| 逻辑高 `--lh` / 默认 `--mobile-h` | 844px |
| 内容左右安全边距（会话） | 16px |
| 半屏顶露出比例 `--sheet-top-pct` | 23%（即 Agent 顶边距画布顶 23%） |
| 半屏顶圆角 `--radius-sheet` | 16px（仅左上、右上） |

### 3.2 半屏模式 `mode-sheet`

**窗体**

- 定位：贴底；`top: 23%`，`bottom: 0`，高度随可视区伸缩
- 圆角：`16px 16px 0 0`
- 底色：实色白 `#ffffff` + 纵向多段浅灰粉渐变（保证不透明，不被首页透出）

**面板渐变（自上而下）**

| 停靠 | 色 |
|------|-----|
| 0% | `#f5f3f1` |
| 8% | `#f6f1f3` |
| 22% | `#f1f1f3` |
| 42% | `#ebebed` |
| 58% | `#e8e8ec` |
| 78% | `#efeff1` |
| 92% | `#faf7f8` |
| 100% | `#ffffff` |

**光斑层 `agent-glow`（叠在底上，边缘透明）**

1. `radial-gradient(190px 122px at 33% -2%, #FFE9F0 → transparent 72%)`
2. `radial-gradient(142px 122px at 114% 0%, #F3E6FA → transparent 72%)`
3. `radial-gradient(238px 238px at 84% 118%, #F6DBE4 → transparent 72%)`
4. `radial-gradient(164px 94px at 15% 92%, #F3E6FA → transparent 75%)`

**半屏语境背景（窗体后方）**

- 首页图：全画布 cover，顶对齐
- 遮罩 scrim：`rgba(0,0,0,.75)`，半屏下可见（opacity 1）
- 全屏下首页图与 scrim：opacity 0 + 不可见（`visibility: hidden`）

### 3.3 全屏模式 `mode-fullscreen`

**窗体**

- `top: 0`，高度 100%，圆角 0
- 背景渐变（165deg）：

| 停靠 | 色 |
|------|-----|
| 0% | `#fae7ed` |
| 14% | `#f7eef8` |
| 32% | `#f1f1f3` |
| 52% | `#ececef` |
| 72% | `#f0f0f2` |
| 100% | `#f8eef5` |

**光斑**

1. `240×170 at 10% -2%`，粉 `rgba(255,210,220,.9)` → 透明 62%
2. `280×190 at 94% 6%`，紫 `rgba(230,210,245,.75)` → 透明 58%
3. `300×220 at 70% 108%`，`rgba(246,219,228,.5)` → 透明 62%

### 3.4 双态切换动效（视觉）

| 属性 | 时长 | 曲线 |
|------|------|------|
| `top` / `height` | 420ms `--dur-sheet` | `--ease-spring` `cubic-bezier(.22,1,.36,1)` |
| `border-radius` / 背景色 | 420ms | `--ease-out` `cubic-bezier(.32,.72,0,1)` |
| scrim / home-bg opacity | 420ms | `--ease-out` |
| 切换过程中机器人 | 短暂 `scale(1.02)`，约 450ms 内恢复 | 同 sheet 时长 |

## 5. 全局结构

自上而下三层（均在 Agent 内）：

```
┌─────────────────────────────────────┐
│ Header（机器人 + 问候 + 操作）        │  flex:none
├─────────────────────────────────────┤
│ Messages Shell（可滚动会话）          │  flex:1
│   └─ Messages + Scroll Hint         │
├─────────────────────────────────────┤
│ Composer（输入条）                    │  flex:none
└─────────────────────────────────────┘
```

- 会话层背景透明，灰度来自面板渐变本身，**不再套一层独立浅灰卡片**。
- Messages 内边距：`6px 16px 28px`；纵向滚动，细滚动条。

- 默认：透明底 + `--btn-stroke` + `--btn-blue`；可带 18×18 图标，gap 6
- 弱化（跳过 / 更多）：字与边 `--btn-muted`
- 点选瞬间 `is-picked`：填充 `--btn-fill`，描边 soft，字重 600，`scale(.97)`，约 160ms 后进入下一界面态

**「更多」面板**

- 收起：`grid-template-rows: 0fr`，opacity 0，无上边距
- 展开：`1fr`，opacity 1，上边距/上内边距 8，顶虚线 `rgba(26,26,26,.08)`
- 过渡约 320ms（rows/margin）+ 240ms（opacity/边色）

### 9.2 开单功能卡 `order-card`

容器同价目功能卡（18 圆角 + 三层阴影）。头区渐变与价目卡一致；左侧机器人图标规格同价目。

#### 9.2.1 草稿态 `data-phase="draft"`

| 元素 | 视觉 |
|------|------|
| 标题 | 「开单确认」15/650 |
| 副标题 | 门店名 · 待批准，11.5/`#7a6f78` |
| Pill | 默认粉紫 pill「待批准」 |
| 字段行 | 左标签 72 宽 / 12px `#8a7f88`；右值 `--fs-body`/500 |
| 可编辑行 | 整行可点（`is-edit` cursor pointer）；金额可出现底边提示线 `rgba(141,138,237,.45)` |
| 业绩/提成 | 两列并排，值 700 + tabular-nums，行 min-height 52 |
| 结账 | 支付 Chip（图标+名，字重 600）+ 金额 |
| 提示文 | 11.5/`#8a7f88`，padding `0 14 10` |
| 底栏 | 左「拒绝」弱化描边（`--btn-muted`）；右「批准」主填充 |

#### 9.2.2 成功态 `data-phase="success"`

| 元素 | 视觉 |
|------|------|
| 标题 / 副标题 | 「开单成功」/「… · 收款完成」 |

| 字段 | 只读；可含「尾号」小字 11.5/`#6a6a72` |

#### 9.2.3 拒绝态呈现

- 开单卡可隐藏或降透明（原型拒绝后隐藏卡）；若保留卡：`opacity .72`，底栏隐藏
- 随后出现追问白卡（见 §9.3）

## 12. 动效规格（编排级）

### 12.1 入场 / 退场

| 名称 | 关键帧 | 时长 | 曲线 |
|------|--------|------|------|
| rise 入场 | y+10、opacity0、scale.985 → 复位 | 340ms | ease-out |
| reply 入场 | x+12、opacity0、scale.97 → 复位 | 340ms | ease-out |
| exit 退场 | 复位 → y+6、opacity0、scale.985 | 200ms | ease-out |
| chip 错峰 | y+6 → 0 | 300ms，delay 40ms×n | ease-out |
| pill pop | scale 1→1.08→1 | 420ms | spring |
| success flash | 阴影闪绿 | 550ms | ease-out |

### 12.2 界面切换编排（视觉顺序）

1. **追问 → 草稿卡**：选中 Chip 高亮约 160ms → 追问卡 exit → 右侧回复泡 reply 入场 + 开单卡 rise 入场  
2. **批准 → 成功**：卡面 success flash + pill pop；同卡内容切换为成功只读；追问白卡 rise + Chip 错峰  
3. **拒绝**：开单卡 exit → 追问白卡 rise（含重新开单）  
4. **半屏 ↔ 全屏**：窗体几何 + scrim + 机器人联动（§3.4）

### 12.3 禁止项

- 全程循环晃动、彩色光晕脉冲超过思考态必要范围
- 每个按钮不同贝塞尔
- 大面积视差 / 3D
