## 1. 文档信息与范围

### 1.1 目标

用统一视觉语言呈现 **AI Agent 全屏对话窗**：首页提醒进场 → 全屏会话 → 价目 / 开单 / 自助归档三类功能结果，在移动端具备轻拟物、品牌粉紫氛围与可测动效，供前端像素级还原。

### 1.2 In / Out

**In（本文包含）**

- 双态窗体：`home` ↔ `fullscreen` 的布局、背景、层级与切换
- 首页 TAB、B2 图标进出提醒、归档 tip 气泡
- Agent 壳：Header / 会话区 / Composer / 滚动提示
- 聊天气泡、思考态、Toast、Chip、折叠区
- 价目表、开单确认卡、自助归档确认卡的表现层规格
- Design Tokens、动效、P0 验收清单

**Out（本文不包含）**

- 接口、库表、审批后台、开单算法与业务规则实现
- 桌面预览壳（左侧原型导航、深色舞台）的产品化要求
- **半屏 Sheet 模式**（已废弃；无 `mode-sheet`、无「展开全屏」、无半屏入口）
- 圆环 / 圆形放大进场（已废弃；仅保留 B2 图标进出）

### 1.3 还原原则

1. **数值优先**：Token 与组件表为准；与原型冲突时先对齐本文再回改原型。
2. **态完整**：可交互控件至少覆盖默认 / 按压 / 选中（若有）/ 禁用或弱化（若有）。
3. **动效可测**：曲线、时长、位移均给数值；尊重 `prefers-reduced-motion`。
4. **功能卡 ≠ 气泡**：价目 / 开单 / 归档结果用轻拟物白卡；Agent 短文用会话白卡；用户消息用粉红气泡。

## 2. 信息架构与模式

### 2.1 双态

| 态 | class / `data-mode` | 用户看到 |
|----|---------------------|----------|
| 首页 | `mode-home` / `home` | 首页图 + TAB；Agent 面板沉出画布下沿 |
| 全屏 Agent | `mode-fullscreen` / `fullscreen` | Agent 占满 390×844；首页图 / TAB / tip 隐藏 |

**默认进入**：首页。  
**打开 Agent**：一律 `setMode("fullscreen")`。  
**关闭**：右上角 × 或侧栏「首页」→ `home`（可重播 B2）。

### 2.2 入口与出口

| 操作 | 结果 |
|------|------|
| TAB 中央 AI 热区 | 全屏；若 tip 亮或有未提示过的待归档单 → 切归档演示 |
| B2 进场机器人点击（`is-open`） | 全屏 |
| 侧栏「价目表 / 开单 / 归档」 | 全屏 + 对应演示面板 |
| 全屏 Header 关闭 | 回首页 |
| 侧栏「首页 · 提醒」 | 回首页并重播 B2 |

### 2.3 三演示（会话内互斥面板）

| Demo | 面板 | 用户首条气泡（示例） |
|------|------|----------------------|
| 价目 | `#panelPrice` | 「我想看一下价目表。」 |
| 开单 | `#panelOrder`（非归档） | 「帮我开单，李女士泡泡染。…」 |
| 归档 | 同开单壳，`setDemoMode("archive")` | 待办 chips → 归档确认卡 |

侧栏「模拟新自助单」仅造数：首页显示 tip；已在全屏则 Toast 提示回首页可见气泡。

## 3. 专章 · UI / UX

### 3.1 Design Tokens

#### 画布与安全区

| Token | 值 |
|-------|-----|
| `--lw` / `--lh` | 390px / 844px |
| `--mobile-scale` | 可视宽 / 390 |
| `--mobile-h` | 基线高 / scale（键盘不改变窗体高） |
| `--safe-bottom` | 系统底安全区换算到逻辑 px |
| `--home-safe-bottom` | `max(--safe-bottom, 8px)`；**只抬 TAB 层** |
| `--kb-h` | 软键盘高度；Composer 避让用 |
| 会话左右边距 | 16px |

#### 色与字

| Token | 值 |
|-------|-----|
| `--ink` | `#1a1a1a` |
| `--muted` | `#626262` |
| `--line` / `--line-2` | `#ededed` / `#e8e8e8` |
| `--font` | `"Noto Sans SC", sans-serif` |
| `--fs-body` | 15px（字号档「中」；小 13 / 大 17） |

#### 按钮（Figma AI 按钮语汇）

| Token | 值 |
|-------|-----|
| `--btn-blue` | `#496fc4` |
| `--btn-stroke` / `--btn-stroke-soft` | `#9fadca` / `#94a8cd` |
| `--btn-muted` | `#a5bde1` |
| `--btn-fill` | `#e9f3ff` |
| `--btn-radius` | 6px |
| `--btn-h` / `--btn-fs` | 34px / 13px |

#### 动效

| Token | 值 |
|-------|-----|
| `--ease-out` | `cubic-bezier(.32,.72,0,1)` |
| `--ease-spring` | `cubic-bezier(.22,1,.36,1)` |
| `--ease-press` | `cubic-bezier(.2,.8,.2,1)` |
| `--dur-press` / `--dur-ui` / `--dur-enter` | `.1s` / `.22s` / `.34s` |
| `--dur-sheet` | `.42s`（首页↔全屏位移与显隐） |

`prefers-reduced-motion: reduce` 时时长近似为 0，取消 chip 入场动画与按压缩放。

### 3.2 首页

#### 首页图与衬托

- `.home-bg`：`assets/agent-chat/home-bg@3x.png`，`cover` + 顶对齐；顶永远贴画布；矮屏只裁底。
- `.home-tab-fade`：390×77 贴画布底，白渐变衬托；全屏下隐藏。

#### TAB（Figma 534:240）

| 项 | 规格 |
|----|------|
| 整图 | `assets/agent-chat/tab/tab-bar@3x.png`，逻辑 390×123 |
| 胶囊 | 图内 344×60 @ x23/y30；毛玻璃底板 `rgba(255,255,255,.94)` + `blur(20px)` |
| 底距 | `bottom: var(--home-safe-bottom)` |
| AI 热区 `.home-ai` | 图内约 50×50 @ left 169 / top 35；B2 结束后 `opacity:1` 可点 |
| 全屏 | TAB `opacity:0` + `visibility:hidden` + 不可点 |

#### B2 图标进出（无圆环）

进入首页（含「首页 · 提醒」）播放一次：

1. 图标从 TAB AI 位放大升起，交接为 WebM 机器人（`assets/tab/agent-keyed.webm`）
2. 展示约 1.6s 后缩回 AI 位，热区可点
3. 关键中点击机器人可直接 `openAgent()` 进全屏

关键参数（逻辑）：图标缩放 ≈ 0.47；进场 ~380ms、出场 ~320ms；`--visual-bottom: 90%` 羽化贴底。

#### 归档 tip 气泡 `#tabTip`

| 规则 | 说明 |
|------|------|
| 文案 | 1 笔：「有待归档自助单」；多笔：`N 笔待归档` |
| 出现 | 首页且存在**尚未提示过**的 pending 自助单 |
| 一次提示 | 点 AI / 点画布 / 进 Agent 时 `dismissTabTip(true)`，将该批记入已提示；同批不再弹 |
| 新单 | 「模拟新自助单」写入新 pending → 回首页可再弹 |
| 视觉 | 贴 AI 热区旁的小气泡；全屏时随首页层隐藏 |

### 3.3 Agent 壳

#### 全屏面板

- `top:0`、高 100%、圆角 0
- 背景 165° 渐变：`#fae7ed → #f7eef8 → #f1f1f3 → #ececef → #f0f0f2 → #f8eef5`
- 光斑：粉 / 紫 / 暖杏三处径向渐变（见原型 `.agent-glow`）
- 首页↔全屏：`transform: translateY(105%)` ↔ `0`，时长 `--dur-sheet`，曲线 spring；切换中加 `is-mode-animating`

#### Header

| 元素 | 规格 |
|------|------|
| 机器人 | `robot@3x.png` 100×100 |
| 问候 | 「Hi，何苏叶店主您好！」+ 副文「内容由Ai生成，请注意核实」 |
| 关闭 | `#btnClose` 仅关闭回首页（无「展开全屏」） |
| 字号 | 小 / 中 / 大 → `--fs-body` 13 / 15 / 17 |

#### 会话区

- `.messages-shell` 透明，浅灰来自面板渐变
- `.messages` 纵向滚动；底留 Composer 空间
- `.scroll-hint`：未滚到底时显示向下 chevron，点按滚到底

#### Composer

- 底贴安全区；输入占位 + 发送
- 键盘弹出用 `--kb-h` 上抬，不改变窗体高度基准

### 3.4 组件

#### 气泡

| 类型 | 外观 |
|------|------|
| 用户 `.bubble-user` | 粉红底、右对齐、圆角会话泡 |
| Agent 短文 `.bubble-agent` | 白卡、不对称圆角、左对齐 |
| 用户追问回复 `.bubble-reply` | 同用户泡，用于选支付后回声 |

#### 思考态 `.thinking`

- 小机器人 + 「思考中」；`aria-live="polite"`
- 演示：侧栏「演示思考 → 出结果」或进入 demo 自动短时思考后出卡

#### Toast

- 价目 `#fnToast`、开单/归档 `#orderFlowToast`：底中 HUD，可带「撤销」
- 约 2s 自动收起

#### Chip

- 追问支付 / 工位员工 / 分类 tab：描边浅蓝底；选中加 `--btn-fill` + 加粗
- 入场可错峰 `motion-chip-in`（~0.3s）
- **禁止原生 `<select>`**

#### 折叠

- 价目「展开剩余」；开单追问「更多支付」面板；工位名册手风琴——同时只开一层

### 3.5 动效与反馈小结

| 场景 | 反馈 |
|------|------|
| 按压 | 主控 `scale(.97–.99)`，`--dur-press` |
| 卡片入场 | 上移 + 淡入，`--dur-enter` |
| 删除 / 归档成功 | Toast；可选撤销窗口 |
| 禁用主按钮 | 降透明 + 不可点；文案或 hint 说明原因 |
| 金额 | `tabular-nums` + 加粗 |

## 4. 价目表

### 4.1 结构

1. 用户气泡 → 思考 → Agent 短文  
2. 结果卡 `session-card`：头（标题「价目表」+ pill「N 在售 · M 停售」）→ 分类 tabs → 列表 → 可选「展开剩余」→ 底栏

### 4.2 行（只读单行）

每行 `.fn-row` 为 **横向单行**，不可点进编辑：

| 区域 | 内容 |
|------|------|
| 左 | 状态点 + 文案（在售绿点 / 停售灰点） |
| 中 | 项目名（ellipsis） |
| 右 | 价格 `¥` + 数字（tabular） |

停售行 `.is-off` 降透明。无「展开改价」内联表单作为主路径（演示以只读为准）。

### 4.3 分类与筛选

- Tabs：全部 / 洗吹 / 剪发 / 染发 / 烫护
- 「只看在售」：过滤停售；pill 与列表同步
- 「去价目表管理」：Toast 示意跳转

### 4.4 左滑删除

- 左滑露出红底删除；确认弹层「删除此项目？」
- 确认后行移除 + Toast（可撤销则恢复）
- 拖拽结束后短暂吞 click，避免误触

### 4.5 空态

筛选后无项：`.fn-empty` 提示文案（如当前分类无在售项）。

## 5. 开单

### 5.1 流程（表现层）

```
用户气泡 → 思考 → 追问白卡（支付 chips）
  → 用户回复泡 → 开单确认卡（待确认）
  → 确认开单 / 拒绝
```

示例用户句：李女士、泡泡染、Tony薛 / 陈嘉怡 / 何苏叶 分大中小工；支付由 chips 选定。

### 5.2 追问卡

- 文案概括客 / 项目 / 工位，问收款方式
- 主 chips：微信 / 支付宝 / 现金 / 会员卡 等（带图标）
- 「更多」展开次要方式；选中后收起追问，出确认卡

### 5.3 确认卡（`data-phase="draft"`）

| 区块 | 表现 |
|------|------|
| 头 | 「开单确认」+ pill「待确认」 |
| Hero | 应付大数字（可点改原价）；项目名；顾客 + 会员类型副文；优惠券 chip（满减示意） |
| 工位 | 大工 / 中工 / 小工：员工 chips、业绩与提成可编辑；摘要行 |
| 收款 | 已选支付 chips；可改金额；**会员卡权益区**（见下） |
| 底栏 | 「拒绝」（危险幽灵）+「确认开单」（主按钮） |
| Hint | 说明可改项；确认才提交 |

**无券基准**：Hero `¥298.00`，业绩合计与提成按工位费率演示（如大工 30% 等）。

### 5.4 会员卡权益（收款区）

持卡场景在收款中选「会员卡」后展示权益列表（**无彩色类型标**，只用名称 + 说明）：

| 类型 | 展示名示例 | 金额/额度展示 | 行为要点 |
|------|------------|---------------|----------|
| 计次 `times` | 泡泡染次卡 | 芯片金额位显示 **「1次」**（非现金） | 抵本单项目次数 |
| 折扣 `discount` | 持卡会员 9 折 | 芯片显示 **「9折」**；应付按 rate 计；**差额由他方支付承担**（如自动补微信） | 会员卡行金额可为 0 |
| 储值 `balance` | 储值余额 | 显示 **¥** 扣减额；不超过可用余额与应付 | 与现金类合计对齐应付 |

选中态：`.mb-pick.is-on` 描边加亮。权益与支付合计不得超过有效应付（折扣后）；超限时自动收敛或禁用多余项。

### 5.5 成功 / 拒绝

| 结果 | 表现 |
|------|------|
| 确认 | pill → 已开单类成功态；跟进短文 + 操作 chips；Toast |
| 拒绝 | 卡收起或失败文案；流程结束，可再开演示 |

## 6. 自助归档

### 6.1 提醒 → 待办

1. 首页 tip（§3.2）→ 点 AI 进全屏并进入归档 demo（若有未提示 pending）
2. 会话内：Agent 引导 + **待归档订单 chips**（顾客 / 金额 / 时间）
3. 点某一笔 → 打开归档确认卡（与开单共用 `order-card` 壳）

### 6.2 归档确认卡

对齐开单确认的信息架构，差异如下：

| 项 | 归档 |
|----|------|
| 标题 / pill | 「归档确认」类 +「待归档」 |
| Hero | 已收金额为主；项目可智能补全（按实付贴近价目）或「快捷开单」 |
| **支付** | **只读**：展示已收渠道与金额，不可改支付方式 |
| 工位 | **与开单相同**：可编辑大中小工员工、业绩、提成 |
| 会员 | 会员单可带历史工位智能回填；散客可带性别示意 |
| 底栏 | 「拒绝」+「确认归档」 |

演示造数示例：李女士 ¥198 微信；男散客 ¥88；王小姐 ¥320（微信+会员卡）等。

### 6.3 已归档

确认后该单 `status: done`；从待办 chips 消失；Toast「已归档」；pill 成功态。拒绝则返回待办列表。

## 7. 验收清单（P0）

对照 `agent-chat.html` 可点验：

### 模式

- [ ] 侧栏无「半屏」「全屏」按钮

- [ ] 全屏点关闭 → 回首页；TAB 与首页图恢复
- [ ] B2 进场可播；无圆环放大

### 首页与 tip

- [ ] 有未提示 pending 时 tip 出现；点 AI 或画布后同批不再出现
- [ ] 「模拟新自助单」后回首页 tip 再出现

### 价目

- [ ] 行只读单行：状态 | 名 | 价
- [ ] 分类 / 只看在售 / 左滑删除确认 / 空态正常

### 开单

- [ ] 追问 chips → 确认卡 Hero/工位/优惠/收款完整
- [ ] 会员权益：计次显示「1次」、折扣「9折」且他方补差、储值显示 ¥；无彩色类型标

### 归档

- [ ] 待办 chips → 确认卡；支付只读；工位可编

### 动效与壳

- [ ] 字号三档生效；滚动提示在未到底时出现
